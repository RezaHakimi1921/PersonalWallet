# PersonalWallet (Arte Wallet)

اپ شخصی مدیریت مالی — دریافت خودکار تراکنش از پیامک بانکی، دسته‌بندی، اقساط/وام، بدهی و طلب، سرمایه‌گذاری، یادآوری، و گزارش/تحلیل. چندکاربره، هر کاربر یه کیف پول کاملاً جدا و خصوصی.

## Stack
- **بک‌اند**: Node.js (Express) + PostgreSQL
- **فرانت‌اند**: PWA وانیلا جاوااسکریپت (بدون فریم‌ورک/بیلد استپ)
- **دیپلوی**: Docker Compose (`db`, `api`, `caddy`) روی یه VPS
- **HTTPS**: Caddy + Let's Encrypt (فعلاً روی دامنه‌ی موقت nip.io)
- **نوتیفیکیشن**: ntfy
- **منبع داده**: پیامک بانکی از طریق iOS Shortcuts → وب‌هوک

## ماژول‌ها
- **حساب‌ها**: چند حساب بانکی/نقدی، موجودی، آستانه‌ی هشدار موجودی کم، تاریخچه‌ی ویرایش دستی موجودی (audit log)
- **تراکنش‌ها**: تأیید تراکنش در انتظار (با مبلغ قابل‌ویرایش)، ثبت دستی، ویرایش، حذف (با گزینه‌ی اختیاری برگردوندن موجودی)، تشخیص خودکار تکراری (هم برای پیامک هم ثبت دستی)، صفحه‌بندی و فیلتر
- **دسته‌بندی‌ها**: هزینه/درآمد، شامل دسته‌های غیرجریانی (انتقال بین حساب، قرض، تسویه بدهی/طلب، وام دریافتی) که از گزارش درآمد/هزینه‌ی واقعی حذف می‌شن
- **قرض/بدهی و طلب**: ثبت قرض جدید یا افزودن به یه بدهی/طلب باز موجود (به‌جای ساختن رکورد تکراری)، تسویه‌ی جزئی/کامل
- **وام دریافتی**: دسته‌ی مخصوص که هم به حساب واریز می‌شه هم خودکار یه قسط ماهانه توی ماژول اقساط می‌سازه
- **اقساط/وام**: پیگیری قسط‌ها، ویرایش کامل (شامل تعداد پرداخت‌شده)، یادآور روز موعد
- **سرمایه‌گذاری**: طلا/سکه/دلار/سایر، به‌روزرسانی خودکار قیمت (BrsApi)، ویرایش کامل جزئیات
- **یادآوری‌ها**: عمومی/قسط/بدهی و طلب/قبض/سایر، با تقویم شمسی
- **تحلیل/گزارش**: مرور ماه‌به‌ماه، مقایسه‌ی ۶ ماه اخیر، سهم درصدی دسته‌ها، بزرگ‌ترین هزینه‌ها، میانگین روزانه + پیش‌بینی پایان ماه، Runway (دوام موجودی)، هزینه‌ی غیرعادی، پرداخت دوره‌ای/اشتراک محتمل، تراکنش‌های مشکوک به تکراری
- **بک‌آپ**: دامپ شبانه‌ی دیتابیس روی سرور (نگهداری کامل) + Scheduled Task روزانه که آخرین بک‌آپ رو به کامپیوتر محلی می‌کشه

## احراز هویت (چندکاربره)
هر کاربر کیف پول کاملاً جدا داره (نه مشترک). ثبت‌نام با شماره موبایل + رمز عبور، به‌علاوه‌ی تأیید OTP (فعلاً **غیرفعاله** تا دامنه‌ی واقعی و پنل پیامکی آماده بشه). نشست از طریق کوکی امن.

- `OTP_ENABLED` (env, پیش‌فرض false): وقتی true بشه، ثبت‌نام نیاز به کد تأیید پیامکی داره.
- `AUTH_REQUIRED` (env, پیش‌فرض true، **فعلاً روی سرور false ست شده**): وقتی false باشه، هیچ‌کس نیاز به ورود نداره و همه‌چی مال همون تک‌کاربر موجوده — این یه حالت موقته تا دامنه/OTP آماده بشه.
- وب‌هوک پیامک بانکی per-user ـه: `/api/webhook/sms/<api_key>` (نه یه آدرس مشترک) — هر کاربر باید api_key خودش رو (از «⚙️ حساب کاربری») توی iOS Shortcuts بذاره.
- پیامک OTP از طریق **ASA SMS** (`api-payamak.com`) با یه پترن ازپیش‌تعریف‌شده (کلمه‌ی کلیدی `code`) ارسال می‌شه. نیاز به `ASA_API_KEY`, `ASA_SENDER`, `ASA_PATTERN_ID` توی `.env`.
